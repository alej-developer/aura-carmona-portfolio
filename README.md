## 🇪🇸 Español

Bienvenido al repositorio oficial del portafolio de **Aura Carmona**, diseñadora de alta costura. Este proyecto web estático ha sido desarrollado para mostrar la elegancia, exclusividad y vanguardia que caracterizan sus colecciones.

### 🌟 Sobre el Proyecto

Este sitio web es un portafolio interactivo, construido con **HTML5, CSS3 y JavaScript Vanilla**, sin depender de frameworks ni plantillas predefinidas. El objetivo es ofrecer una experiencia web rápida, fluida y con un diseño premium que refleje la estética y el lujo de la marca.

### 📁 Arquitectura de Carpetas

La estructura del proyecto está organizada de la siguiente manera:

```text
/
├── assets/
│   ├── css/          # Hojas de estilo globales y específicas de componentes
│   ├── images/       # Imágenes, logotipos y recursos gráficos de alta resolución
│   └── js/           # Scripts de JavaScript (lógica de UI, animaciones, etc.)
├── src/              # Archivos fuente (HTML, componentes, etc.)
└── README.md         # Documentación del proyecto
```

### 🚀 Despliegue y Alojamiento

Este proyecto se encuentra alojado y mantenido en el repositorio de GitHub: **[alej-developer](https://github.com/alej-developer)**.

## 🇬🇧 English

Welcome to the official portfolio repository of **Aura Carmona**, a high fashion designer. This static web project has been developed to showcase the elegance, exclusivity, and avant-garde nature that characterize her collections.

### 🌟 About the Project

This website is an interactive portfolio built with **HTML5, CSS3, and Vanilla JavaScript**, without relying on any predefined frameworks or templates. The goal is to provide a fast, smooth web experience with a premium design that reflects the brand's aesthetics and luxury.

### 📁 Folder Architecture

The project structure is organized as follows:

```text
/
├── assets/
│   ├── css/          # Global and component-specific stylesheets
│   ├── images/       # High-resolution images, logos, and graphic assets
│   └── js/           # JavaScript scripts (UI logic, animations, etc.)
├── src/              # Source files (HTML, components, etc.)
└── README.md         # Project documentation
```

### 🚀 Deployment & Hosting

This project is hosted and maintained in the GitHub repository: **[alej-developer](https://github.com/alej-developer)**.
